## Re-run the analysis

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python analysis/week1_explore.py   # week 1 figures
python analysis/week2_models.py    # 2.2, 2.4, 2.5b, 2.6
python analysis/week2_nulls.py     # 2.8, 2.9, shuffle battery, grow-your-own-Marvel
```

Figures are written to `docs/assets/weekN/`. Every number quoted in a post is also dumped to
`analysis/week2_results_models.json` and `analysis/week2_results_nulls.json`, so nothing on the site
is hand-typed.

`week2_nulls.py` takes optional section names (`clustering`, `battery`, `reciprocity`, `paradox`,
`grow`, `widget`) if you only want to regenerate part of it — the full run takes a few minutes,
mostly in the 100 × 14,340 degree-preserving edge swaps.

## The explorable

`docs/assets/week2/shuffle-machine.js` runs degree-preserving double edge swaps on the real giant
component, in the browser, with no dependencies. Its data is regenerated by
`python analysis/week2_nulls.py widget` into `docs/assets/week2/marvel_gc.js`.
